# Byte-Pair Tokenizer:
  This repo contains algorithmic implementation for **Byte-Pair Tokenizer**.
  ## What are tokens:
  - Tokens are just a integer representation for text(not just a text, it also can include integer, emoji, etc ... ). For e.g, a-z has their interger values 97-122, so for this `minbpe_gpt_tokenizer` text it has integer representation as `109,105,110,98,112,101,95,103,98,116,95,116,111,107,101,110,105,112,101,114` but this representation is too long but we need integer representation as minimal as possible. 
  - On way to represent text as integer as minimal as possible, Do you remember how we (humans) usually trying to read or write words, for e.g, when i trying to read or write **`tokenizer`** as usually i would go like **```to ke ni zer```** now it's only have `4` chunk's instead of `9`. What if we have algorithm that would take our sentence (words) and gives integer representation as minimal as possible in way how we usually represent. **Byte-Pair Tokenizer** does exactlly what we needed, for given sentence it gives integer representation as minimal as possible. Each integer representation called *token* instead of just int, cause each token represent's chunk in a sentence or word.
